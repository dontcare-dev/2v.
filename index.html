Privacy Policy

Last updated: July 2026

TL;DR: ^^ only stores data necessary for functionality. We do not sell or share your data. You can request deletion at any time.

1. Information We Collect

^^ collects and stores the following data to provide its core functionality:

  • User IDs: Used for economy balances, warnings, levels, and user-specific settings.
  • Server IDs: Used to store server-specific configurations (moderation settings, economy data, etc.).
  • Message Content: Only when explicitly used in commands (e.g., /reminder, /note, /poll).
  • Command Usage: We log command usage anonymously for performance monitoring.

2. How We Use Your Data

  • To provide and maintain the bot's core features
  • To improve and optimize the bot's performance
  • To enforce moderation and security features
  • To store user preferences and progress (economy, levels, etc.)

3. Data Storage

  • Data is stored locally in a bot_data.json file on the host server
  • No external databases or third-party storage services are used
  • Data is not shared, sold, or transmitted to any third party
  • All data is stored securely with appropriate access controls

4. Data Retention

  • Data is retained indefinitely unless manually deleted or requested for removal
  • You can request deletion of your data by contacting the developer
  • Server administrators can clear server-specific data via /economyreset and similar commands

5. Third-Party APIs

  • Nekos.best: Used for anime reaction GIFs. No data is transmitted to this API other than the category requested.
  • Discord API: All data is processed through Discord's official API in accordance with their Terms of Service.
  • Lanyard API: Used to display developer presence. Only your Discord User ID is sent.

6. Discord Developer Terms Compliance

^^ complies with Discord's Developer Terms of Service and Platform Policy:

  • We do not collect or store message content without explicit user command
  • We do not share user data with any third party
  • We provide clear means to request data deletion
  • We use data only for the functionality described in this policy
  • We maintain appropriate security measures to protect stored data

7. User Rights

As a user of ^^, you have the following rights:

  • Right to Access: Request a copy of your stored data
  • Right to Rectification: Correct inaccurate data
  • Right to Erasure: Request deletion of your data
  • Right to Restrict Processing: Limit how your data is used

8. Data Deletion

To request deletion of your data, contact the developer via Discord at @deathy or through the developer's portfolio.

9. Changes to This Policy

This Privacy Policy may be updated from time to time. We will notify users of any material changes by updating the "Last updated" date at the top of this policy.

10. Contact

If you have any questions about this Privacy Policy, please contact:

  • Developer: Deathy
  • Discord: @deathy
  • Portfolio: dontcare-dev.github.io/Deathy.2v.dev

✅ Compliance: ^^ is committed to protecting your privacy and complying with Discord's Developer Terms of Service, GDPR, and applicable data protection laws.

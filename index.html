Privacy Policy

Last updated: July 2026

TL;DR: ^^ only stores data necessary for functionality. We do not sell or share your data. You can request deletion at any time.

1. Information We Collect

^^ collects and stores the following data to provide its core functionality:

  • User IDs: Used for economy balances, warnings, levels, and user-specific settings.
  • Server IDs: Used to store server-specific configurations.
  • Message Content: Only when explicitly used in commands.
  • Command Usage: Logged anonymously for performance monitoring.

2. How We Use Your Data

  • To provide and maintain the bot's core features
  • To improve and optimize the bot's performance
  • To enforce moderation and security features
  • To store user preferences and progress

3. Data Storage

  • Data is stored locally in a bot_data.json file on the host server
  • No external databases or third-party storage services are used
  • Data is not shared, sold, or transmitted to any third party

4. Data Retention

  • Data is retained indefinitely unless manually deleted or requested for removal
  • You can request deletion of your data by contacting the developer

5. Discord Developer Terms Compliance

^^ complies with Discord's Developer Terms of Service and Platform Policy.
